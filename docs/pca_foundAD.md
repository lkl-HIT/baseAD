# 研究计划：基于 PCA/SubspaceAD 思路增强 FoundAD

## 1. 研究目标

本文档旨在基于当前 `FoundAD` 项目与 `SubspaceAD` 论文/实现，提出一套可执行的研究方案，用于回答以下问题：

1. `FoundAD` 与 `SubspaceAD` 的核心建模差异是什么。
2. 如果以 `FoundAD` 为基础，`SubspaceAD` 的统计子空间建模思想是否可以用于增强 `FoundAD`。
3. 若可以，应优先从哪些模块切入，形成低风险、可验证、可逐步扩展的实验路线。

本计划的核心判断是：**可以将 `SubspaceAD` 作为 `FoundAD` 的补充模块，而不必直接替代 `FoundAD`。最有价值的方向不是“把 FoundAD 改成纯 PCA 模型”，而是让 PCA 子空间建模成为 FoundAD 的辅助表征、辅助打分或辅助归纳偏置。**

---

## 2. 两篇文章/两个模型的核心总结

### 2.1 FoundAD 的核心思想

`FoundAD` 的出发点是：基础视觉编码器已经隐式学习到了正常图像的潜在流形，异常样本会在特征空间中偏离该流形。因此，模型不必重建图像像素，而是可以直接在特征空间内学习一个轻量的投影器，将偏离正常流形的异常特征重新映射回正常区域。

其核心流程可概括为：

1. 用冻结的视觉骨干提取 patch-level 特征。
2. 用 CutPaste 等方式构造伪异常，模拟特征偏移。
3. 训练一个轻量 ViT predictor，使其输出逼近正常特征。
4. 推理时以输入特征与 predictor 输出之间的残差作为异常分数。

`FoundAD` 的关键优点是：

- 充分利用 foundation encoder 的表征能力。
- 用可学习的非线性 predictor 建模复杂的正常流形。
- 参数量相对较小，训练目标简单清晰。
- 对多类别 few-shot 场景友好。

`FoundAD` 的潜在不足是：

- 仍然需要训练 predictor。
- 对位姿变化、旋转、空间错位等情况可能仍然敏感。
- 图像级分数聚合主要依赖固定 Top-K，数据集间可能需要调参。

### 2.2 SubspaceAD 的核心思想

`SubspaceAD` 的出发点是：在强大的基础特征之上，也许并不需要再训练复杂模块，只要用少量正常图像估计一个“正常 patch 特征的低维线性子空间”，就可以通过重建残差完成异常检测。

其核心流程可概括为：

1. 用冻结的 DINOv2 提取 patch-level 特征。
2. 聚合多个中间层特征，形成更稳健的 patch 表征。
3. 对正常 patch 特征集合拟合 PCA 子空间。
4. 推理时计算每个 patch 到该子空间的重建残差。
5. 通过 top 1% 均值等方式聚合为图像级异常分数。

`SubspaceAD` 的关键优点是：

- 无需训练，方法极简。
- 统计解释性强，异常分数清楚对应“偏离正常子空间的程度”。
- 对少样本设定非常自然，因为 PCA 直接用正常样本估计分布。
- 模型存储与部署成本低。

`SubspaceAD` 的潜在不足是：

- PCA 本质上是线性建模，对复杂非线性正常流形的表达能力有限。
- 若正常变化本身非常复杂，单一子空间可能欠拟合。
- 更适合作为每个类别独立建模的方法，不如 FoundAD 的统一可学习结构灵活。

## 3. 两个模型的结构对比

| 维度 | FoundAD | SubspaceAD |
| --- | --- | --- |
| 正常性建模方式 | 可学习的非线性投影器 | 线性 PCA 子空间 |
| 训练需求 | 需要训练 predictor | 无需训练，仅统计拟合 |
| 特征处理 | 常以单层/少数层特征为主 | 强调多层 token 聚合 |
| 异常分数 | 输入特征与投影特征残差 | 输入特征与子空间重建残差 |
| 图像级聚合 | Top-K 均值 | TVaR / top 1% 均值 |
| 优势 | 非线性能力强、可适应复杂流形 | 极简、可解释、轻量 |
| 风险 | 训练依赖合成异常质量 | 线性假设可能过强 |

从研究视角看，两者并非完全对立，而是落在同一个框架的两个端点：

- `FoundAD`：用**学习型非线性映射**来建模正常流形。
- `SubspaceAD`：用**统计型线性子空间**来建模正常流形。

因此，一个自然的问题是：**能否将统计子空间作为 FoundAD 的辅助先验，引导、补充或校验 predictor 的输出。**

---

## 4. 核心研究假设

本项目建议围绕以下四个研究假设展开：

### 假设 H1：多层特征聚合能够提升 FoundAD 的稳定性

`SubspaceAD` 的经验表明，多层中间特征的平均或分组聚合往往比单层特征更稳健，尤其在细粒度缺陷与复杂背景下更有优势。若将该思想引入 `FoundAD`，有望提升 predictor 输入的表征质量。

### 假设 H2：PCA 残差与 FoundAD 残差具有互补性

`FoundAD` 的残差来自“输入特征与学习型投影输出的差异”，`SubspaceAD` 的残差来自“输入特征与统计子空间重建的差异”。二者虽然都衡量偏离正常性，但感知的偏差类型可能不同，因此存在互补空间。

### 假设 H3：PCA 可作为 FoundAD 的辅助归纳偏置

在少样本条件下，训练式方法容易受样本数量、合成策略和初始化影响。若在 FoundAD 中加入 PCA 子空间约束或 PCA 辅助评分，可提升训练稳定性并减少错误泛化。

### 假设 H4：图像级聚合策略仍有优化空间

`FoundAD` 当前主要依赖固定 Top-K 聚合，而 `SubspaceAD` 的 top-ratio 聚合具有更强的自适应性。将固定 K 替换为按比例聚合，可能减少不同数据集之间的人工调参。

---

## 5. 总体方案设计

本研究不建议直接废弃 `FoundAD` 的 predictor，而建议采用“从弱耦合到强耦合”的渐进路线，分三阶段推进。

### 5.1 第一阶段：低风险融合

目标：**不改变 FoundAD 主训练框架，只在输入特征和输出分数上融合 SubspaceAD 思路。**

优先尝试以下三个改动：

#### 方案 A：多层特征聚合替代单层特征

思路：

- 在 `VisionModule._extract()` 中不只取单个中间层。
- 读取多个中间层 patch token。
- 对这些层做 mean pooling，或 concat 后接一个轻量线性映射。
- 将聚合后特征送入现有 predictor。

预期收益：

- 提升特征稳定性。
- 提高对细粒度缺陷和局部纹理变化的敏感度。
- 缓解单层选择过于依赖经验的问题。

实现难度：低到中等。

#### 方案 B：PCA 辅助打分

思路：

- 保持 FoundAD 原训练流程不变。
- 在每个类别的正常训练特征上额外拟合一个 PCA 子空间。
- 推理时同时计算：
  - `FoundAD score`
  - `PCA residual score`
- 最终图像分数与像素分数采用加权融合或 max 融合。

可选融合方式：

1. 线性融合：`S = alpha * S_foundad + (1 - alpha) * S_pca`
2. 最大响应：`S = max(S_foundad, S_pca)`
3. 标准化后求和：适用于两种分数分布差异较大时

预期收益：

- 用统计模型补充学习模型。
- 当 predictor 对某些异常不敏感时，PCA 可提供额外检测信号。
- 几乎不改训练流程，适合作为第一条验证路线。

实现难度：低。

#### 方案 C：图像级聚合改为 top-ratio

思路：

- 将 `AD.py` 中的固定 Top-K 聚合改为 top-ratio 聚合。
- 例如对 patch 分数的前 1% 或前 2% 取均值。
- 与当前固定 K 进行并行实验比较。

预期收益：

- 让聚合方式随 patch 数量自动适配。
- 降低不同输入尺寸和不同骨干下的调参负担。

实现难度：很低。

### 5.2 第二阶段：中等耦合融合

目标：**让 PCA 不只是独立打分器，而是参与 FoundAD 的训练或特征约束。**

#### 方案 D：PCA 约束损失

思路：

- 先在正常特征上拟合 PCA 子空间。
- 在训练 predictor 时，除原始重建损失外，再加入子空间一致性约束。
- 例如约束 predictor 输出落在正常 PCA 子空间附近。

可行的损失形式：

1. 约束 predictor 输出到 PCA 子空间的残差尽量小。
2. 约束异常输入经过 predictor 后，其输出比原始输入更接近 PCA 子空间。
3. 同时保留原始正常特征对齐损失，形成双重监督。

潜在收益：

- 让 predictor 的学习过程带有“统计正常性先验”。
- 减少纯学习式投影器过拟合到合成异常模式的风险。

潜在风险：

- PCA 是线性空间，若约束过强，可能限制 predictor 的非线性建模能力。
- 权重选择不当可能导致定位能力下降。

实现难度：中等。

#### 方案 E：PCA 引导的难样本挖掘

思路：

- 用 PCA 残差识别正常样本中最“边缘”的 patch 或图像。
- 在训练期间对这些样本赋予更高权重，或做更强增强。
- 使 predictor 更关注“正常流形边界”区域。

预期收益：

- 提升边界样本的建模能力。
- 改善对细小异常与边界伪影的区分。

实现难度：中等。

### 5.3 第三阶段：高耦合融合

目标：**探索新的混合模型结构，而不再局限于现有 FoundAD 训练形式。**

#### 方案 F：双分支正常性建模

思路：

- 一条分支为现有 FoundAD predictor。
- 另一条分支为 PCA/KPCA 子空间建模。
- 推理时输出两张异常图，再通过学习到的门控或规则融合。

适用场景：

- predictor 擅长复杂非线性异常。
- PCA 擅长对训练不足或统计离群点做快速校验。

预期收益：

- 更强的鲁棒性与可解释性。

风险：

- 系统复杂度增加。
- 实验变量增多，调参成本上升。

实现难度：较高。

## 6. 推荐的主线实验路线

为了提高研究效率，建议按如下顺序推进，而不是同时铺开所有方向。

### 第一优先级

1. `多层特征聚合`
2. `PCA 辅助打分`
3. `top-ratio 图像级聚合`

这是最值得优先验证的一组方案，因为：

- 改动局部，风险低。
- 不破坏当前 FoundAD 主干结构。
- 最容易判断 SubspaceAD 思路是否真的对 FoundAD 有增益。

### 第二优先级

4. `PCA 约束损失`
5. `PCA 引导的难样本挖掘`

这两项更偏研究创新，但也更依赖前一阶段结论。

### 第三优先级

6. `双分支混合模型`

该方向适合作为论文增强点或后续扩展，不建议一开始就投入主要精力。

## 7. 具体实验设计

### 7.1 数据集与设置

建议沿用 `FoundAD` 当前主要实验设置：

- 数据集：`MVTec-AD`、`VisA`
- few-shot 设置：`1-shot`、`2-shot`、`4-shot`
- 骨干优先级：`DINOv3`、`DINOv2`

若算力有限，可先在以下子集快速验证：

- `VisA 1-shot`
- `MVTec 1-shot`

因为该设定最能体现少样本条件下统计先验是否有价值。

### 7.2 评估指标

保持与 FoundAD 一致：

- Image-level AUROC
- Image-level AUPR
- Pixel-level AUROC
- PRO

同时建议新增以下分析：

- 各类别增益分布，而不是只看平均值
- 误检类型分析
- 对旋转/背景污染类别的专项分析

### 7.3 对照组

建议至少包含以下实验组：

1. `FoundAD baseline`
2. `FoundAD + multi-layer features`
3. `FoundAD + PCA score`
4. `FoundAD + top-ratio aggregation`
5. `FoundAD + multi-layer + PCA score`
6. `FoundAD + multi-layer + PCA score + top-ratio`

若第一阶段有效，再继续：

7. `FoundAD + PCA regularization`
8. `FoundAD + dual-branch hybrid`

### 7.4 消融实验建议

建议重点消融以下变量：

- PCA 保留方差阈值，例如 `0.95 / 0.99 / 0.995`
- 多层特征范围，例如 `last-1 / last-3 / middle-7`
- 融合方式，例如 `sum / max / normalized sum`
- top-ratio 比例，例如 `0.5% / 1% / 2%`
- 是否采用正常图增强后再拟合 PCA

## 8. 工程落地点建议

### 8.1 FoundAD 中最适合改动的位置

#### 特征提取侧

- 文件：`foundad/src/foundad.py`
- 目标：扩展 `VisionModule._extract()`，支持多层 token 聚合

#### 训练侧

- 文件：`foundad/src/train.py`
- 目标：若做 PCA 正则，可在 `_step()` 中增加约束损失

#### 推理与评估侧

- 文件：`foundad/src/AD.py`
- 目标：
  - 增加 PCA 子空间加载与拟合逻辑
  - 增加 PCA residual anomaly map
  - 增加 score fusion
  - 将固定 Top-K 改为可配置的 top-ratio

### 8.2 建议新增的模块

建议参考 `SubspaceAD` 的结构，在 `FoundAD` 内新增如下轻量模块：

- `foundad/src/utils/pca.py`
  - 用于 PCA 拟合、保存、加载、重建与残差计算

- `foundad/src/utils/score_fusion.py`
  - 用于多分数归一化与融合

- `foundad/src/utils/feature_aggregation.py`
  - 用于多层 token 聚合

这样可以把研究性改动和现有主流程解耦，便于对照实验。

## 9. 预期收益与风险判断

### 9.1 预期收益

若研究假设成立，预期可以获得以下收益：

1. 提升 few-shot 下的稳定性，尤其是在样本更少时。
2. 提升对小缺陷、局部纹理异常、背景伪影的区分能力。
3. 提升对跨类别或复杂背景情况下的鲁棒性。
4. 增强结果解释性，因为 PCA 分支可以提供清晰的统计异常依据。

### 9.2 潜在风险

1. PCA 可能与 predictor 学到的非线性映射重复，带来有限增益。
2. 若融合不当，可能抬高误检率。
3. 多层特征 concat 可能显著增加 predictor 的输入维度和训练成本。
4. PCA 子空间是 per-class 的，若当前 FoundAD 训练流程强调统一模型，需要额外设计类别级统计缓存。

---

## 10. 最终建议

综合现有文章理解与代码结构，最推荐的主线方案如下：

### 推荐主线

先做一个**轻量级混合版本**：

1. 在 `FoundAD` 中加入多层特征聚合。
2. 在每个类别的正常特征上拟合 PCA。
3. 推理时融合 `FoundAD residual` 与 `PCA residual`。
4. 将图像级分数从固定 Top-K 改为可配置 top-ratio。

这是当前最平衡的路线，因为它同时具备：

- 明确的理论动机
- 较低的工程成本
- 清晰的消融边界
- 较强的论文扩展价值

### 不推荐作为第一步的方向

- 直接用 PCA 完全替换 FoundAD predictor
- 一开始就做复杂双分支联合训练
- 在没有完成基础对照前就引入 Kernel PCA、门控网络等更复杂模块

这些方向虽然可能有效，但不适合作为第一阶段主线，因为会模糊贡献来源，不利于判断到底是统计建模本身起作用，还是系统复杂化带来了偶然增益。

- 总结增益来源

---

## 12. 一句话结论

`SubspaceAD` 的价值不在于替代 `FoundAD`，而在于为 `FoundAD` 提供一个简单、稳定、可解释的“正常子空间先验”。从研究和工程两方面看，**最值得优先尝试的方向是：多层特征聚合 + PCA 辅助打分 + top-ratio 聚合**，它们最有可能在不显著破坏现有框架的前提下，为 `FoundAD` 带来稳定增益。
